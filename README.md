## ⚠️ Important Safety Information

The flashlight should be used responsibly.

Users should avoid:

- Looking directly into a bright LED light.
- Using the flashlight near sensitive eyes.
- Leaving the flashlight continuously active when unnecessary.
- Using the flashlight in situations where it could create a safety hazard.
- Using the device flashlight in a way that may cause excessive device heating.

Device temperature and battery consumption may increase during prolonged flashlight usage.
